# PRD — EduStat: Платформа аналитики для школьных учителей

**Версия:** 1.0  
**Дата:** май 2025  
**Статус:** Draft  
**Авторы:** Продуктовая команда EduStat

---

## 1. Обзор продукта

### 1.1 Описание

EduStat — веб-платформа для автоматической аналитики успеваемости и социального состава классов, ориентированная на учителей и заместителей директора (завучей) общеобразовательных школ Казахстана. Пользователь загружает Excel-файл с данными об учениках, платформа формирует готовые отчёты в форматах Word (.docx) и Excel (.xlsx).

### 1.2 Проблема

Учителя и завучи тратят значительное время на ручное составление отчётности: успеваемость по четвертям, баллы СОР и СОЧ, социальный состав классов. Данные разбросаны по файлам, нет единого инструмента для визуализации и выгрузки отчётов в нужном формате.

### 1.3 Решение

Единая платформа, в которой достаточно один раз загрузить данные — и система автоматически строит всю аналитику, генерирует отчёты по любому срезу и экспортирует в форматы, принятые в школьном документообороте.

### 1.4 Цели продукта

- Сократить время формирования отчётов с нескольких часов до нескольких минут
- Стандартизировать форматы аналитики внутри школы
- Обеспечить визуализацию данных в режиме дашборда
- Поддерживать выгрузку в Word и Excel для передачи в администрацию

## 2. Пользователи

### 2.1 Целевая аудитория

| Роль | Описание | Основные задачи |
|---|---|---|
| **Учитель-предметник** | Ведёт один или несколько предметов в нескольких классах | Загрузить баллы, посмотреть динамику по предмету, скачать отчёт СОР/СОЧ |
| **Классный руководитель** | Отвечает за конкретный класс | Анализ успеваемости класса, социальный портрет, выгрузка отчёта |
| **Завуч (зам. директора)** | Курирует несколько классов / всю параллель | Сводная аналитика по всей школе, сравнение классов, годовой отчёт |

### 2.2 Контекст использования

- Доступ с ПК в учительской или дома
- Работа преимущественно в конце учебной четверти или по итогам года
- Требования к скорости отклика невысокие, важна точность данных и качество выгрузки

## 3. Функциональные требования

### 3.1 Загрузка данных

**FR-01 — Загрузка файла Excel**
- Пользователь загружает файл формата `.xlsx`, `.xls` или `.csv`
- Система автоматически определяет колонки: ФИО, класс, предмет, баллы СОР (1–4), баллы СОЧ (1–2), учебный год, четверть
- При несоответствии структуры — вывод ошибки с подсказкой об ожидаемом формате
- Поддержка одновременной загрузки нескольких классов в одном файле

**FR-02 — Шаблон файла**
- Возможность скачать шаблон `.xlsx` с правильной структурой колонок
- Шаблон содержит инструкцию на первом листе

**FR-03 — Управление загруженными файлами**
- Список загруженных файлов с датой, статусом обработки, количеством учеников
- Возможность удалить файл
- История загрузок (последние 10)

---

### 3.2 Аналитика успеваемости

**FR-04 — Дашборд**
- Сводные показатели: средний балл, количество отличников, успеваемость (%), группа риска
- Фильтры: класс, учебный год, четверть, предмет
- Динамика показателей к предыдущему периоду (стрелка вверх/вниз, дельта)

**FR-05 — Анализ СОР (Суммативное оценивание за раздел)**
- Баллы по каждому разделу для каждого ученика
- Средний балл по классу на каждый СОР
- До 4 СОРов на предмет за четверть
- Визуализация: столбчатая диаграмма по разделам

**FR-06 — Анализ СОЧ (Суммативное оценивание за четверть)**
- Баллы за каждую четверть (I–IV) по предметам
- До 2 СОЧ в год (I полугодие, II полугодие)
- Динамика от четверти к четверти

**FR-07 — Квартальная аналитика**
- Средний балл по каждой четверти
- Сравнение классов внутри параллели
- Прогресс отдельного ученика по четвертям

**FR-08 — Годовая аналитика**
- Итоговые оценки за учебный год
- Рейтинг предметов по среднему баллу
- Количество отличников, хорошистов, троечников, неуспевающих
- Сравнение текущего года с предыдущим (если данные загружены)

---

### 3.3 Аналитика класса

**FR-09 — Социальный портрет класса**
- Распределение по полу: мальчики / девочки
- Состав семьи: полная, неполная, многодетная, под опекой
- Визуализация: круговая диаграмма + таблица

**FR-10 — Сводная таблица по классам**
- Сравнительная таблица: класс, кол-во учеников, м/д, средний балл, отличники, успеваемость, группа риска
- Экспорт таблицы в Excel

---

### 3.4 Генерация отчётов

**FR-11 — Типы отчётов**

| Тип | Описание |
|---|---|
| Отчёт по СОР | Баллы всех учеников за каждый СОР, средние по классу |
| Отчёт по СОЧ | Итоги за четверть/полугодие |
| Отчёт об успеваемости | Сводка по предметам за выбранный период |
| Состав класса | Социальный портрет класса |
| Квартальный отчёт | Комплексный отчёт по итогам четверти |
| Годовой отчёт | Итоговый документ по всем классам за год |

**FR-12 — Параметры отчёта**
- Выбор класса (один или несколько)
- Выбор периода (четверть, полугодие, год)
- Выбор предмета (один или все)
- Выбор формата: Word (.docx) или Excel (.xlsx)

**FR-13 — Экспорт в Word (.docx)**
- Профессиональное оформление: заголовок школы, учебный год, класс, учитель
- Таблица с данными, оформленная по стандарту школьной документации
- Подпись и дата
- Язык: русский (с возможностью добавить казахский)

**FR-14 — Экспорт в Excel (.xlsx)**
- Многолистовой документ: каждый класс/предмет на отдельном листе
- Встроенная условная форматировка (зелёный — 5, жёлтый — 4, оранжевый — 3, красный — 2)
- Сводная таблица на первом листе

## 4. Нефункциональные требования

### 4.1 Производительность

- Загрузка файла до 5 МБ — обработка не более 10 секунд
- Формирование отчёта Word/Excel — не более 15 секунд
- Страница дашборда — загрузка не более 3 секунд

### 4.2 Безопасность

- Авторизация по логину и паролю
- Разграничение доступа: учитель видит только свои классы, завуч — все классы
- Данные об учениках хранятся с соблюдением требований к персональным данным (ПД)
- HTTPS обязательно

### 4.3 Совместимость

- Браузеры: Chrome 100+, Firefox 100+, Edge 100+
- Устройства: приоритет ПК, мобильная версия — базовый просмотр
- Форматы экспорта: совместимость с Microsoft Office 2016+ и LibreOffice

### 4.4 Доступность

- Язык интерфейса: русский (первая версия)
- Язык отчётов: русский / казахский (переключение в настройках)

## 5. Дизайн и UX

### 5.1 Корпоративный стиль

- Основная палитра: тёмно-синий (#0A1628), синий (#1565C0), голубой (#2196F3), бирюзовый (#00BCD4), золотой (#FFB300)
- Фоновая сетка, градиентные акценты — строгий, профессиональный вид
- Типографика: Geologica (заголовки), JetBrains Mono (числовые данные)

### 5.2 Структура интерфейса

```
Header (логотип + навигация + роль + аватар)
├── Sidebar (разделы, классы, экспорт)
└── Main Content
    ├── Дашборд (статистика + графики)
    ├── Загрузка данных
    ├── Создать отчёт (конструктор)
    └── Классы (таблица + состав)
```

### 5.3 Ключевые экраны

**Дашборд**
- Строка KPI-карточек (средний балл, отличники, успеваемость, группа риска)
- Вкладки: СОР / СОЧ / Годовая
- Столбчатая диаграмма баллов по предметам
- Круговая диаграмма состава класса
- Прогресс по кварталам (4 кольца)
- Блок последних отчётов

**Загрузка данных**
- Drag-and-drop зона с подсветкой
- Список требований к файлу
- Журнал загруженных файлов со статусом

**Конструктор отчётов**
- Карточки типов отчётов (6 вариантов)
- Форма параметров: класс, период, предмет, формат
- Кнопки: сформировать, предпросмотр, скачать Word, скачать Excel

**Классы**
- Сводная таблица с данными по всем классам
- Социальный портрет класса (диаграммы пол + состав семьи)

## 6. Структура данных

### 6.1 Ожидаемые колонки файла

| Колонка | Тип | Описание |
|---|---|---|
| ФИО | Текст | Фамилия Имя Отчество ученика |
| Класс | Текст | Например: «9А», «10Б» |
| Пол | Текст | М / Ж |
| Дата рождения | Дата | дд.мм.гггг |
| Состав семьи | Текст | полная / неполная / многодетная / опека |
| Предмет | Текст | Название дисциплины |
| Четверть | Число | 1, 2, 3 или 4 |
| СОР 1 | Число | Балл за первый СОР |
| СОР 2 | Число | Балл за второй СОР |
| СОР 3 | Число | Балл за третий СОР |
| СОР 4 | Число | Балл за четвёртый СОР |
| СОЧ | Число | Балл за суммативное за четверть |
| Учебный год | Текст | Например: «2024–2025» |

## 8. Roadmap

### Фаза 1 — MVP (3–4 недели)
- Загрузка Excel-файла и парсинг данных
- Дашборд: KPI-карточки + диаграммы

- СОР и СОЧ отдельными отчётами
- Квартальный и годовой отчёт
- Социальный портрет класса
- Конструктор отчётов (выбор параметров)

### Фаза 3 — Продвинутые функции (3–4 недели)
- Многолетняя аналитика (сравнение годов)
- Индивидуальные карточки учеников
- Рассылка отчётов по email
- Поддержка казахского языка в отчётах
- Мобильная версия

### Фаза 4 — Масштабирование
- Мультишкольность (управление несколькими школами)
- Интеграция с МИС/электронными журналами
- API для сторонних систем
